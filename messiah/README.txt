《彌賽亞：萬願者》網頁版

檔案：
  index.html    遊戲本體（所有程式、事件、角色都在這個檔案裡）
  michael.webp  彌迦爾立繪

上架方式：把整個 messiah 資料夾上傳到你的網站，網址就是 你的網域/messiah/
兩個檔案必須放在同一個資料夾。

要改內容時常改的位置（在 index.html 裡搜尋）：
  const EV=       事件庫（標題、描述、選項、數值影響）
  const ACTS=     夜晚的相處選項
  const OPEN=     彌迦爾的夜晚台詞（依人格分類）
  const CHARS=    像素角色的外觀設定
  const WHO=      每個事件會出現哪些角色
